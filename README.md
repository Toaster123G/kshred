## Introduction
Light **Windows clear tool, for delete all junked & malware files permanently** from the command line. It is designed for both **default users and devs**. You can use it to quickly remove unnecessary files, folders, project files, build artifacts, temporary data, and other unwanted data from your system.

The utility is lightweight, fast, and focused on one task: **deleting files and folders without unnecessary complexity.**

## System requirements
- CPU architecture: x86_64, x64
- OS: Windows 10-11
